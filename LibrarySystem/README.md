# Библиотечный каталог

Проект WinForms на C# для Visual Studio. Основное окно оформлено в стиле `Theater.Version2`: заголовок, панель поиска и действий, вкладки с общей таблицей и статусная строка. Интерфейс находится в `LoginForm.Designer.cs` и `MainForm.Designer.cs`; формы можно открывать в конструкторе Visual Studio и менять визуально.

## Что реализовано

- Вход библиотекаря и хеширование пароля в базе.
- Версия 1: каталог книг, CRUD-операции и поиск перебором загруженного списка.
- Версия 2: поиск по началу названия или автора с использованием индексов Microsoft Access.
- Таблицы и поля базы названы по-русски: `Библиотекари`, `Книги`, `ТестовыеЗаписи`.
- Вычислительный эксперимент: замер полного перебора и запроса по индексу для таблиц на 1 000, 5 000 и 10 000 записей.
- Используется база `Microsoft Access База данных.accdb` в папке проекта; при отсутствии файл создается рядом с исполняемым файлом.

## Запуск

1. Откройте `LibrarySystem.sln` в Visual Studio с поддержкой разработки классических приложений .NET Framework.
2. Установите Microsoft Access Database Engine (ACE) подходящей разрядности. Приложение использует провайдер `Microsoft.ACE.OLEDB.12.0`; Windows и Office сами по себе не всегда устанавливают его.
3. Соберите и запустите проект. Таблицы, индексы и демонстрационные книги будут созданы автоматически.

Демо-учетная запись: логин `librarian`, пароль `Library123!`.

Эксперимент добавляет временные строки в таблицу `ТестовыеЗаписи`, измеряет два способа поиска и удаляет тестовые строки после измерения. Результат зависит от компьютера, версии ACE и текущей нагрузки.
