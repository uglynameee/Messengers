# Сравнительный анализ мессенджеров

| Критерий | Telegram | VK Мессенджер | WhatsApp |
| :--- | :--- | :--- | :--- |
| **1. Синхронизация** | Облачная (все устройства) | Облачная (внутри VK) | Привязка к смартфону |
| **2. Шифрование** | В секретных чатах (E2E) | На серверах VK | Везде по умолчанию (E2E) |
| **3. Лимит файлов** | До 2 ГБ (Premium — 4 ГБ) | До 4 ГБ | До 2 ГБ |
| **4. Каналы/Блоги** | Отличная платформа | Средне (связаны с VK) | Базовый функционал |
| **5. Платформа ботов** | Лучшая в классе | Средняя (через VK API) | Только для бизнеса (платно) |
| **6. Лимит в группах** | До 200 000 человек | До 500 человек | До 1024 человек |
| **7. Звонки / Эфиры** | До 1000 зрителей | Без ограничений | До 32 человек |
| **8. Скрытие номера** | Полное (по `@username`) | Полное (по VK ID) | Нельзя скрыть в чатах |
| **9. Доп. функции** | Своя крипта, Web Apps | Музыка, клипы, стикеры | Инструменты для бизнеса |
| **10. Реклама и платность** | Подписка Premium, реклама | Реклама VK, стикеры | Бесплатен (платный API) |
